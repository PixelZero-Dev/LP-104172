# 🐍 Treinos de Python

Esta pasta é destinada exclusivamente aos meus **treinos e estudos de Python**.

Aqui ficam exercícios, exemplos, testes e atividades que estou refazendo para praticar e reforçar meu aprendizado.

## 📚 Sobre esta pasta

Diferente das pastas de projetos, esta pasta **não precisa estar perfeitamente organizada**. É normal encontrar:

- Exercícios repetidos;
- Códigos refeitos várias vezes;
- Exemplos diferentes do mesmo assunto;
- Testes de código;
- Códigos incompletos;
- Tentativas que não funcionaram;
- Alterações feitas durante os estudos;
- Exercícios antigos que estou refazendo para fixar o conteúdo.

O objetivo principal é **praticar**, e não produzir códigos perfeitos.

## 🎯 Objetivo

Utilizar esta pasta como um espaço para:

- Praticar a linguagem Python;
- Fixar os conteúdos estudados;
- Refazer atividades;
- Testar diferentes formas de resolver um problema;
- Identificar e corrigir erros;
- Acompanhar minha evolução durante o aprendizado.
