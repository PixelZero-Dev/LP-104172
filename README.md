## 📚 Sobre o Projeto

O repositório foi estruturado seguindo a sequência pedagógica do curso. Cada pasta representa um módulo de aprendizado, contendo exercícios práticos que reforçam o conteúdo estudado em sala de aula.

### Objetivos do Projeto

- ✅ Praticar os conceitos básicos de programação
- ✅ Desenvolver o raciocínio lógico e a resolução de problemas
- ✅ Aplicar estruturas condicionais e de repetição
- ✅ Resolver situações do cotidiano através de código
- ✅ Construir uma base sólida para o aprendizado de programação

## 🗂️ Estrutura do Repositório

| Pasta | Conteúdo | Conceitos Principais |
|-------|----------|----------------------|
| **1 - Variaveis** | Declaração e uso de variáveis | Tipagem estática e dinâmica, `str`, `int`, `float` |
| **2 - Entrada_de_Dados** | Entrada de dados do usuário | Função `input()`, conversão de tipos |
| **3 - Operacoes_Matematicas** | Cálculos e operações | Média, desconto, salário, maior/menor valor |
| **4 - If-Else** | Estruturas condicionais | `if`, `else`, `elif`, operadores lógicos |
| **5 - Switch_Case** | Estrutura de múltipla escolha | `match-case` (Python 3.10+) |
| **6 - Laco_for** | Laços de repetição com `for` | `range()`, contadores, acumuladores |

| **8 - Vetores** | Listas (vetores) | `list`, `append()`, percorrer listas |
| **Praticas para treinar** | Exercícios extras | Prática livre dos conteúdos |
| **Revisão** | Exercícios de consolidação | Integração de vários conceitos |
