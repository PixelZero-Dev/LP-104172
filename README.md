# LP-104172 — Atividades de Lógica de Programação (SENAI)

Repositório com as atividades e exercícios desenvolvidos durante o curso de **Lógica de Programação** no **SENAI**.

O projeto está organizado de forma progressiva, seguindo a ordem de aprendizado da disciplina, utilizando a linguagem **Python**.

---

## 📚 Sobre o Projeto

Este repositório foi estruturado por módulos temáticos. Cada pasta contém exercícios práticos que reforçam o conteúdo estudado em sala de aula.

### Objetivos
- Praticar os conceitos fundamentais de programação
- Desenvolver o raciocínio lógico
- Aplicar estruturas condicionais e de repetição
- Resolver problemas do cotidiano através de código

---

## 🗂️ Estrutura do Repositório

| Pasta | Conteúdo |
|-------|----------|
| **1 - Variaveis** | Declaração de variáveis, tipos de dados estáticos e dinâmicos |
| **2 - Entrada_de_Dados** | Entrada de dados com `input()` |
| **3 - Operacoes_Matematicas** | Cálculos (média, desconto, salário, maior/menor, etc.) |
| **4 - If-Else** | Estruturas condicionais (`if`, `else`, `elif`) |
| **5 - Switch_Case** | Estrutura `match-case` (cardápio, dias da semana, pagamento, etc.) |
| **6 - Laco_for** | Laços de repetição com `for` (tabuada, pares/ímpares, contagem regressiva, soma) |
| **7 - Laco_while** | Laços de repetição com `while` (validação de notas, login, menus) |
| **8 - Vetores** | Listas (vetores) – armazenamento e manipulação de vários valores |
| **Praticas para treinar** | Exercícios extras para praticar |
| **Revisão** | Exercícios de revisão que consolidam os conteúdos anteriores |

## 🛠️ Tecnologias Utilizadas

- **Python 3** (recomendado 3.10 ou superior por causa do `match-case`)
- Bibliotecas padrão: `os`, `time`, `datetime`

## 🚀 Como Executar os Exercícios

1. Clone o repositório:
```bash
git clone https://github.com/PixelZero-Dev/LP-104172.git
cd LP-104172
```

2. Execute qualquer arquivo `.py`:
```bash
python "1 - Variaveis/1_tipos_dados_estaticos.py"
```

> **Dica:**  
> A maioria dos exercícios usa `os.system('cls')` (limpa a tela no Windows).  
> No Linux ou macOS, troque por `os.system('clear')`.

## 📌 Destaques dos Exercícios

- **Variáveis**: Tipagem estática vs dinâmica
- **Operações Matemáticas**: Média, desconto, antecessor/sucessor, maior e menor valor
- **Condicionais (If-Else)**: Alistamento militar, aposentadoria, classificação de notas, IMC, compra de maçãs
- **Match-Case**: Cardápio, dias da semana, sistema de pagamento (à vista / à prazo)
- **Laço For**: Tabuada, números pares/ímpares, contagem regressiva, acumuladores
- **Laço While**: Validação de notas, sistema de login com tentativas, menus interativos
- **Vetores (Listas)**: Armazenamento de notas, nomes e cálculos com listas
- **Revisão**: Exercícios que unem vários conceitos
